# 隐私与联网边界

“L-1 File To Text v2.1.0 公开内测版”的应用代码在本机处理用户主动选择的媒体、临时音频、任务记录和输出文件。本内测版不设计上传媒体或转写文本到 L-One 服务，也不调用云端推理。

## 已核实的边界

- 安装包不含模型权重或 FFmpeg。首次配置仅在用户确认后联网下载资源；不会上传用户媒体或转写文本。
- 资源下载会连接公开的 Hugging Face 模型文件来源和 GitHub 的 FFmpeg 发布来源；资源中心在下载前显示对应 URL、许可证和大小。
- 下载完成后模型和 FFmpeg 保存到用户选择的资源目录，不写入程序安装目录。
- 应用数据默认保存在 `%LOCALAPPDATA%\L-One\L-1 File To Text`；输出默认保存到源文件同目录或用户明确选择的目录。

## 卸载与删除

卸载程序只应移除程序目录和快捷方式，不自动删除应用数据、用户自行配置的模型目录或输出文件。确认不再需要后，用户可手动删除对应目录。

## 支持排查

排查时只应收集应用版本、系统版本、错误摘要和用户明确同意提供的最小复现材料。不要上传或公开原始媒体、完整转写、模型目录或完整日志。
