# L-1 File To Text v2.1.0 公开内测版

这是一个 Windows 本地音视频转写候选版，用于验证本地识别、任务记录和 Markdown 输出流程。

## 当前状态

本包的用户可见名称是“L-1 File To Text v2.1.0 公开内测版”。它用于邀请测试，不是稳定版。

当前已验证的是 FireRed 本地识别候选路线、单个正式 Markdown 输出、任务记录与 Windows 安装启动。大批量真实文件仍在测试中，不能据此推断所有文件、语言或场景均已验收。

## 先知道这些限制

- 安装包不包含语音识别模型，也不包含 FFmpeg（视频读取组件）。
- 首次打开会在本机读取 CPU、内存、显卡和磁盘信息，并列出基础资源建议。用户确认后，资源中心下载 FireRed 中文识别模型和 FFmpeg，显示来源、许可证、大小、进度与失败原因，并校验固定 SHA-256。
- FireRed 目前只用于中文真实任务测试候选；英文路线不在本次首配承诺中。
- 英文内容会保留原文；本候选不交付中文翻译稿，也不生成带时间轴的中文字幕（`.srt` / `.vtt`）。
- `<sil>` 这类识别标记会清理。中文内容中出现长英文片段时只提示人工复核，不会自动判为歌词或删除。
- 本候选不适合把转写结果直接当作已校对事实、正式字幕或公开知识库正文。

## 已测试的能力

首次配置时选择资源目录，确认下载“FFmpeg 视频读取组件”和“FireRedASR2 中文本地识别模型”。两个资源均显示来源、许可证与大小；下载完成后资源中心显示“已安装”。随后添加一个中文音视频文件，得到一个 Markdown 转写文件；输出默认放在源文件同目录，也可以选择其他目录。任务完成界面会保留总耗时、识别耗时、模型/设备和源时长倍率。

支持范围、质量和速度只以随包发布事实包中的具体证据为准。没有模型、FFmpeg 或相应本机配置时，任务会明确失败，而不是调用云端推理。

## 安装、卸载与回退

仅运行来源可信且 SHA-256 一致的安装包。Windows 10/11 64 位是本轮已核验的安装目标。

卸载可从 Windows“已安装的应用”或安装目录内的卸载程序执行。卸载不应自动删除用户的输出、模型或 `%LOCALAPPDATA%\L-One\L-1 File To Text` 中的任务记录；卸载前请自行备份需要保留的内容。

目前公开稳定渠道仍是 `2.0.8`；公开内测版只应从 L-One 指定的测试入口取得。回退应由发布负责人提供经过核验的 `2.0.8` 安装包，不能从未知来源下载旧版。

## 校验安装包

在安装包所在目录打开 PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\L-1 File To Text Setup v2.1.0 公开内测版.exe'
```

将结果与同目录 `SHA256SUMS` 或 `release-manifest.json` 中的值逐字符比较。不一致时不要安装。

本包构建完成后，此处会写入预期 SHA-256：`B4CB233299B9660EAC81F702A7215DA13401AEFB79D6591EB651C3F47CDA3406`。

隐私和联网边界见 `PRIVACY.md`；模型与组件边界见 `MODEL_SOURCES.md`；第三方许可见 `THIRD_PARTY_NOTICES.md` 与 `SBOM.json`。
