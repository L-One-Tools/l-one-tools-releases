# L-1 网页拓印 v0.2.2 公开内测

L-1 网页拓印是 Chrome 浏览器扩展：它把当前打开的普通网页保存成一张 PNG 长图，或一段自动向下浏览的视频。

这是公开内测，不是正式稳定版。

## 安装

1. 从本版本对应的 GitHub Release 下载 `L-1-网页拓印-v0.2.2-内测候选包.zip`。
2. 解压 ZIP。
3. 在 Chrome 地址栏输入 `chrome://extensions`，打开“开发者模式”。
4. 选择“加载已解压的扩展程序”，选择解压后的 `L-1 网页拓印 v0.2.2 内测版` 文件夹。
5. 在扩展菜单中固定“L-1 网页拓印”。

## 使用与保存

打开普通图文网页，保持该标签页在前台，点击扩展后选择“网页长图”或“网页录制”。生成的 PNG、MP4 或 WebM 由浏览器下载功能保存到浏览器设定的位置。

## 支持范围与限制

- 已验证：Chrome 116+ 的基础加载、启用、长图、录制和移除流程；测试使用 L-One 自有页面。
- 未覆盖：Edge、360、Safari、不同 Windows 版本、极长页、无限加载页、特殊动画和浏览器受保护页面。
- 录屏默认无声；部分网页结果可能有上下黑边、滚动条或固定导航。
- 任务进行时不能切换标签页。

请不要保存含密码、付款信息、私人聊天或其他敏感资料的网页。

## 校验

在 PowerShell 中运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\L-1-网页拓印-v0.2.2-内测候选包.zip'
```

预期值：

```text
FB9441ED595E24E6A6B9E8DD3D994E353B412FA22EFC44C923AD7E7D499DF055
```

不一致时请停止安装，从本版本 GitHub Release 重新下载。

## 移除与回退

打开 `chrome://extensions`，找到“L-1 网页拓印”，选择“移除”。如本版本被撤回，请停止使用、移除扩展，并以仓库中标记为可用的后续版本为准。
